# PDF and Word versions

The essay is also available as:

- `paper_draft.pdf` (23 pages, letter size, with charts)
- `paper_draft.docx` (Word)
- `paper_package.pdf` (56-page research package: config hashes, results, brief, protocol, novelty check, vetted quotes, pilot)

These are binary files, and the connector used to build this repository uploads only text. They will be added to this folder separately. The canonical text is [`../paper_draft.md`](../paper_draft.md).
